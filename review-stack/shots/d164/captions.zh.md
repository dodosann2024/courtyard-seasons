# d164 证据说明

## 改动对象

帐篷右前方晾毯架的横梁（`src/desert.js` 中 `rack()` 里的 `bar`，现命名为 `rackBar`；晾毯架位置 `RACK = TENT + 右 5.1 m + 前 0.9 m`，横梁离地 1.82 m、长 3.6 m）。
main 上它是一根 6 棱、40 个顶点的直圆柱，与支杆共用纯色材质 `#6e4a2c`。帐篷自带的木杆是帐篷模型（单一 Tripo 网格、单张贴图）的一部分，按要求不动；火堆边的坐木不是横梁，也不动。

本轮只换了这根横梁的几何体和材质；支杆、叉头、毯子、水囊、陶罐、帐篷和其他物体都没动，也没有新增物体。横梁的随机数用自己的种子，岛上共用的随机序列不受影响，其他物体的布局与 main 完全一致。

## 横梁特写

- `A_bar_close_day_before_after.png`：白天特写，左边 main，右边本分支。风沙顺盛行风方向把软的早材磨掉，硬的晚材纹理凸成一道道顺纹的棱，迎风面和上风端磨得最深；截面不规则（略扁、有起伏、沿长度扭转），两叉之间微微下垂；端头磨圆并开裂成 V 形裂口；有深长的顺纹干裂、旧磕痕，还有几个硬节子凸出来、木纹绕着节子分开。颜色是日晒褪成的银灰，只有裂缝里留着深褐（裂缝内部按遮蔽处理，烈日下也不会被照亮），背阴的下侧稍偏褐。
- `A_bar_close_day_before.png` / `A_bar_close_day_after.png`：同一画面的单张原图。
- `A_bar_detail_day.png`：白天特写局部放大（2 倍），能看清凸起的纹棱、节子和裂缝。
- `A_bar_close_dusk_before_after.png`：黄昏特写，左 main 右本分支。光照照常起作用：暖色斜光下纹棱一面亮一面暗，裂缝仍是深色。
- `A_bar_close_dusk_before.png` / `A_bar_close_dusk_after.png`：同一画面的单张原图。
- `A_bar_close_rain_before_after.png`（附加）：大雨后（`uWetC = 1`），左 main 右本分支。木头淋湿后整体变深、表面变光滑，积了沙的纹沟变深得少一些；雾凇和薄雪也照常覆盖（沿用场景原有的 frostMat）。

沙和磨损：一点吹来的沙卡在横梁上侧的纹沟里，以及横梁搭在两个叉头上的位置。场景里这根横梁没有绳子（不新增物体），所以“绳子缠绕处的磨损”放在横梁搭在叉头上、被反复磨蹭的那一圈（更光滑、颜色更暗、略微磨细），以及毯子搭过的上沿（轻微磨亮）。

## 中景

- `B_bar_mid_tent.png`：中景，帐篷在左，晾毯架横梁在右，银灰横梁和深色支杆、彩色毯子能分开看清。
- `B_bar_mid_tent_before_after.png`：同一中景，左 main 右本分支，帐篷和其他物体完全一样。拍中景前把鸵鸟放到画面外的空沙地上（鸵鸟模型和行为未改，仍是 `ostrich_v2ag`），画面里没有鸵鸟。

## 数据

- `perf.json`：同一次运行中本分支和 main 交替测量（`tools/e2e/perf.mjs`，模拟 iPhone 13，CPU 降速 4 倍）。每帧 JS 平均：本分支 14.9 ms，main 14.8 ms（上限 17.0 ms）；加载后没有超过 200 ms 的帧。
- `d164-report.json`：横梁前后对比（main：40 顶点圆柱；本分支：`rackBar`，36176 顶点 / 72128 三角形，材质 `des164bar`）、版本号核对、飞蜥选取结果。

生成脚本：`tools/e2e/d164-proof.mjs`（`bar` / `ver` / `agama` / `pair`）。

未改动：帐篷、鸵鸟（`ostrich_v2ag`，鸵鸟文件无 diff）、岛底沙流（仍是分开的一股股，不是整圈沙帘）、打水漂（仍暂停）、风吹沙、沙丘缓慢变化、雨天效果。
