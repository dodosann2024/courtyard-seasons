# d169 截图说明

本次只调晾毯架横梁（rackBar）风蚀槽的三个参数 cav / bot / crest，以及槽底反照率的色调；面数不变，着色器没有改，其他木件和篝火石的顶点数据与 main 完全一致。
所有对比都用 d167/d168 的同一机位（`bar`，右支杆一侧，迎风面），机位写在道具自己的坐标系里（见 `d169-report.*.json` 的 `cams`）。
左右对比图：左边是修改前（main，#168，desert.3eef4c54ac.js），右边是修改后（本分支，desert.c064423117.js）。
三联图从左到右依次是：#164（desert.f1b14a2f7f.js，约 6.7 万面）、#168 / main、本分支（d169）。

## 问题

- #168 的槽底压得太狠：遮蔽值 cav = 1 让木头着色器几乎挡掉了全部阳光，槽底只剩偏蓝的天光，再加上槽底反照率是中性灰，结果成了冷调的炭黑色。
- 白天最暗 10% 像素的平均颜色约为 0.10 / 0.096 / 0.092（几乎无色相），而 #164 是偏暖的 0.142 / 0.113 / 0.087。
- 脊线又被额外漂白（crest = 0.28），亮部 p95 为 0.789，高于 #164 的 0.735。
- 黄昏时尤其明显：槽像用黑笔画出来的线，而不是风蚀出来的木头裂纹。

## 调整（只动 rackBar 的 flow 参数）

| 参数 | #168 / main | 本分支 | 作用 |
| --- | --- | --- | --- |
| cav | 1 | 0.55 | 槽底遮蔽减半，阳光仍能照进去一部分，阴影保持暖色 |
| bot | 0.5 | 0.25 | 槽底反照率少压一档 |
| crest | 0.28 | 0 | 脊线不再额外漂白 |
| tv（槽底分通道压暗） | 0.78 / 0.78 / 0.76 | 0.68 / 0.75 / 0.83 | 红通道压得少、蓝通道压得多，槽底保持木头本身的棕色 |
| ckc（主槽底裂缝色） | 0.02 / 0.018 / 0.016 | 0.022 / 0.012 / 0.006 | 恢复 #167 的暖深棕 |

调整后不像黑线，提亮后也没有发灰，所以没有走离线高模（约 6.7 万面）烘焙法线 + AO 的后备方案。

## 起伏和明暗（`relief.json`）

- 用同一个脚本 `tools/e2e/d167-relief.py`，同样只取画面 x 230–650 px，取样方法没有改。
- 本轮在脚本里新增两项，取样像素与原指标完全相同：
  - `dark10RGB`：横梁上最暗 10% 像素的平均颜色（sRGB）。
  - `ridgeP95`：横梁亮度的第 95 百分位（脊线亮度）。
- 原有指标的结果与 d168 的 relief.json 逐位一致，说明取样没有变。

| 指标 | #164 白天 | #168 白天 | 本分支白天 | #164 黄昏 | #168 黄昏 | 本分支黄昏 |
| --- | --- | --- | --- | --- | --- | --- |
| dark | .249 | .264 | .260 | .277 | .305 | .264 |
| hp | .119 | .144 | .114 | .123 | .133 | .108 |
| std | .206 | .221 | .196 | .212 | .224 | .194 |
| 最暗 10% RGB | .142 / .113 / .087 | .101 / .096 / .092 | .172 / .138 / .105 | .106 / .082 / .068 | .107 / .089 / .078 | .147 / .116 / .092 |
| 最暗 10% G/R、B/R | .80 / .62 | .95 / .91 | .80 / .61 | .77 / .64 | .83 / .73 | .79 / .63 |
| 脊线 p95 | .735 | .789 | .743 | .706 | .763 | .717 |

- 槽底色相：白天 G/R、B/R 从 #168 的 .95 / .91（灰黑）回到 .80 / .61，与 #164 的 .80 / .62 基本相同。
- 白天深暗 .260，接近 #164 的 .249（目标 0.20–0.25 附近）；黄昏 .264，低于 #164 的 .277。
- 脊线 p95：白天 .789 → .743，黄昏 .763 → .717，只比 #164 高约 1%。
- hp 比 #168 低（白天 .144 → .114），比 #164 的 .119 低约 4%：槽不再是黑线，对比自然变小。

## 手机网格（3,360 面）

- 修改前（#168）：上沿几条槽在稀疏网格上连成一条较宽的近黑色带。
- 修改后：变成柔和的暖棕色，没有看到块状黑带，所以手机路径没有另外减弱。
- 手机网格的 hp 从 .161 降到 .100，比桌面降得多：手机上的槽看起来更平一些。
- 手机最暗 10%：白天 .135 / .119 / .104 → .160 / .122 / .088；黄昏 .118 / .096 / .082 → .121 / .090 / .072。
