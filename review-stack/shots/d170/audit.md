# d170 沙漠场景审计表

每一项都先在 main（`desert.c064423117.js`）上测量、截图，再判定；只修判为「弱」的项。
本分支包：`desert.2ccd4efe17.js`（面板「版本 2ccd4e」）。

| 项目 | main 现状（实测） | 判定 | 本轮改动 |
|---|---|---|---|
| 风吹沙：方向 | 沙面流沙条带和波纹都跟着风向走；固定三个风向（40°/120°/308°），条带方向随之转动 | 正常 | 无（沙粒改成沿风拉长的短线后，方向也能从沙粒上看出来） |
| 风吹沙：强度 | 风力 0.15 不起沙（saltation 0，阈值正确）；0.5 和 1.0 区别也在。但风力 1.0 时沙面流沙条带是叠加高光，最亮处达到漫反射的十几倍，沙面成片过曝、斑驳发白；跳跃沙粒画成灰色圆形光斑，浮在脊上方 2–3 米 | 弱 | 流沙高光改为软上限（饱和曲线，最多 0.42），条带下的波纹阴影同时减淡，不再成片发白；沙粒改为沿自身飞行方向拉长的短线，颜色跟沙面光照走；平沙上贴地跳 1.5–9 厘米，脊上的沙被抛起后顺背风坡落下 |
| 沙丘：随时间变形 | 脊线缓慢蠕移、高度/弯度/扭转随时间变化；波纹约 1.5 厘米/秒向下风迁移，持续风向改变后波纹方向跟着转 | 正常 | 无 |
| 沙丘：随风向变形 | 形状只随时间变化，不管风从哪边吹（斜风 40 分钟后扭转 sk = 0.08） | 弱 | 斜风慢慢把一侧的角喂长、整体向下风偏（跟着沙丘时钟慢慢积累，不会瞬间跳变）：同一斜风 40 分钟后 sk = 1.47；风转到另一侧后变为 −1.24 |
| 雨：人眼高度可见 | 人眼高度（1.6 米）看出去雨线稀疏：雨开/关差异中变化超过 20 灰度的像素，沙地 1.31%、帐篷 0.28%、湖 0.32% | 弱 | 在相机周围加两层跟随相机的雨盒（4.5 米近层、12 米中层，中层从 3 米外接管），近处雨线最短 0.3 米：沙地 2.49%、帐篷 1.89%、湖 1.99%，俯视 0.50%→2.48% |
| 雨：沙地 | 雨坑、变暗、雨后慢慢变干（湿度 1 → 雨停 1 分钟 0.72 → 约 4.8 分钟回到 0，脊上先干、成片斑驳地干） | 正常 | 无 |
| 雨：帐篷 | 布面淋湿变暗、雨水顺布流下、檐口滴水、布面溅水、雨打帐篷的声音（CI 检查 roofShare 0.38） | 正常 | 无（帐篷网格、支架、三脚架都没动） |
| 雨：绿洲湖 | 涟漪圈、水花冠、雨线 | 正常 | 无 |
| 西奈飞蜥：晒太阳 | 晴天在地面趴着晒（雄性越晒越蓝） | 正常 | 无 |
| 西奈飞蜥：爬椰枣树 | 会爬上树干（片中 5 秒从 0.2 米爬到 0.99 米，树高 7.6 米） | 正常 | 无 |
| 西奈飞蜥：雨中躲树冠 | 大雨 4 分钟后两只都停在树冠下（雄 7.6 米树，顶下 0.50 米；雌 11.8 米树，顶下 0.70 米，均等于目标位置） | 正常 | 无 |

## 没动的东西（核对过）

- 鸵鸟 GLB 仍是 ostrich_v2ag。
- 晾毯架横梁 / 木头 / 篝火石：26 个网格的顶点指纹与 main 完全一致（`geo_dune.json`）。
- 毯子、水袋、陶罐、帐篷支架 / 三脚架 / 立杆几何没改。
- 岛底沙流仍是 54 股独立竖直金色细流，只在底部变细；打水漂仍暂停；云海、SW 缓存版本、面板「版本 xxxxxx」标签都在。
