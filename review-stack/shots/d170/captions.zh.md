# d170 截图与视频说明

本轮是审计：先在 main（`desert.c064423117.js`）上把风吹沙、沙丘变形、三种地面的雨、西奈飞蜥的行为逐项测量、截图，再只修判为「弱」的三项（见 `audit.md`）。没有加任何新元素。
左右对比图：左边是修改前（main，desert.c064423117.js），右边是修改后（本分支，desert.2ccd4efe17.js），同一机位、同一天气、同样的模拟时长。
视频都是 12 帧/秒，场景冻结后逐帧推进再截图（SwiftShader 软件渲染，画质比真机低）；字幕烧在画面左下角。
所有人眼高度镜头都是离沙面 1.6 米。

## 一、风吹沙

### 修了什么

- 强风（风力 1.0）时，main 的沙面流沙条带是叠加高光，最亮处达到漫反射的十几倍，沙面成片过曝发白，看上去像反光的塑料而不是流沙。
- main 的跳跃沙粒画成灰色圆形光斑，浮在沙丘脊上方 2–3 米，不像沙。
- 本分支：流沙高光改成软上限，条带下的波纹阴影同时减淡；沙粒改成沿自己飞行方向拉长的短线，平沙上贴地跳 1.5–9 厘米，脊上的沙被抛起后顺背风坡落下。

### 对比图

- `W_crest_w1_before_after.jpg`：沙丘脊，风力 1.0。左边脊面发白、脊上漂着光斑；右边脊面保持沙色，流沙条带看得清，沙从脊上被吹向背风坡。
- `W_flat_w1_before_after.jpg`：平沙地，风力 1.0。左边整片沙面过曝；右边条带细、方向一致，不再刺眼。
- `W_crest_w05_before_after.jpg`、`W_flat_w05_before_after.jpg`：风力 0.5，两边几乎一样（中风本来就正常，改动没有影响它）。

### 视频

- `V_wind_strength_flat.mp4`、`V_wind_strength_crest.mp4`：同一块沙，风力 0.15 → 0.5 → 1.0 各 2 秒。0.15 不起沙；0.5 沙粒贴地跳、条带淡；1.0 条带成片、脊上扬沙。实测起沙强度 0 / 0.38 / 1，流沙强度 0 / 0.44 / 2.15。截帧：`V_wind_strength_*_strip.jpg`。
- `V_wind_direction_down.mp4`、`V_wind_direction_crest.mp4`：强风，风向依次固定为 40°、120°、308°。脚下沙面的条带方向随风向转；沙丘脊上，沙一次落向右侧，一次因为风朝镜头吹而藏在脊后，一次被抛向右上方。截帧：`V_wind_direction_*_strip.jpg`。

## 二、沙丘变形

### 修了什么

- main 的沙丘会随时间慢慢蠕移、长高、变弯、波纹迁移（这些正常），但形状不管风从哪边吹。
- 本分支：风斜着吹时，慢慢把迎风那一侧的角喂长、整体向下风扭；风转到另一侧，扭转也慢慢反过来。

### 对比图

- `D_dune_oblique40min_before_after.jpg`：同一斜风（和脊线成 60°）吹 40 分钟后。左边（main）扭转 sk = 0.08，形状和无风时一样；右边 sk = 1.47，沙丘明显向下风一侧偏。

### 视频

- `V_dune_timelapse.mp4`：延时，每帧 8 分钟，共 384 分钟。前一半风从一侧斜吹，后一半转到另一侧。实测扭转 sk：1.29 → 1.40 → −1.24。截帧：`V_dune_timelapse_strip.jpg`（第 8、192、384 分钟）。

## 三、雨（人眼高度）

### 修了什么

- main 从人眼高度看出去雨线太稀，大雨也不太像大雨：雨开/关差异中变化超过 20 灰度的像素，沙地 1.31%、帐篷 0.28%、湖 0.32%。
- 本分支：在相机周围加了两层跟着相机走的雨（4.5 米内的近层、12 米内的中层，中层从 3 米外接管），近处雨线最短 0.3 米。同样的指标变为沙地 2.49%、帐篷 1.89%、湖 1.99%。
- 沙地、帐篷、湖各自的雨效果（雨坑、淋湿变暗、帐篷流水滴水溅水、湖面涟漪和水花、雨声）main 上就是对的，本轮没有改。

### 对比图

- `R_tent_eye_hrain_before_after.jpg`：大雨 90 秒，帐篷前人眼高度。右边雨线明显更密，帐篷黑布前能看到雨。
- `R_lake_eye_hrain_before_after.jpg`：大雨，绿洲湖边。右边湖面前有成片雨线，左边只有零星几根。
- `R_sand_eye_hrain_before_after.jpg`：大雨，沙地。

### 视频（各 6 秒：雨前 1 秒、大雨 3 秒、雨停后变干延时 2 秒）

- `V_rain_sand_eye.mp4`：沙地被雨打出坑、变暗，雨停后从脊上开始、成片地慢慢变干。
- `V_rain_tent_eye.mp4`：帐篷布淋湿变暗，雨停后慢慢干回原色。
- `V_rain_lake_eye.mp4`：湖面涟漪和水花，雨停后水面恢复平静。
- 单帧：`V_rain_*_0dry.jpg`（雨前）、`_1rain.jpg`（大雨）、`_2after1min.jpg`（雨停 1 分钟，湿度 0.72）、`_3after4.8min.jpg`（雨停 4.8 分钟，湿度 0，已干）；四格并排：`V_rain_*_strip.jpg`。
