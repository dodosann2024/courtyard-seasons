# d171 截图与视频说明

本轮只修一件事：骆驼走路、跪下、卧倒时蹄子离地（漂浮）。没有加任何新元素，鸵鸟、沙瀑、木架/营火石、毯子/水囊/陶罐/帐篷、打水漂、西奈飞蜥、风吹沙、沙丘变形、雨和 #170 的改动都没动。
左右对比图：左边是修改前（main，desert.2ccd4efe17.js），右边是修改后（本分支，desert.013a914945.js），同一机位、同一时刻、同样的模拟步数。
所有贴地镜头都在骆驼侧面，离沙面 0.45 米（视频 0.5 米）。画面左下角字幕里的「离沙」数字是该帧实测的四蹄（或四肢最低点）离沙高度：正数是悬空，负数是陷进沙里。
SwiftShader 软件渲染，画质比真机低。

## 一、原因

- main 的骆驼身体高度只按身体尺度的几个点去贴沙面，蹄子本身没有参与。平沙上走路基本贴地，但一上沙丘坡（最陡约 26°），四只蹄子会一起悬空或陷沙，幅度到 20 厘米左右。
- 跪下、卧倒两段动画本身会把折起的前膝和胸口留在沙面上方约 0.28 米，所以卧着的骆驼像是浮在沙上。

## 二、修了什么

- 每帧在 CPU 上对两种骆驼各约 400 个预选的腿、蹄、腹底顶点做蒙皮，得到每条腿和腹底的实际最低点，再和该处沙面高度（hTop）比较。
- 身体的俯仰按最低的前肢和后肢接触点找平；站、跪、卧时的左右侧倾按左右腿找平；走路时侧倾跟随四蹄下面沙面的横坡。随后整只骆驼下沉到最低接触点陷沙 0.6 厘米。沙丘随时间变形时这些都跟着走。
- 站立或走路时，已经踩定（贴地面不动）但因为姿势扭转而差几厘米够不到沙的那条腿，从肩/髋处放下去贴沙；在空中摆动的腿不动。
- 只改了 `src/desert.js` 里骆驼的落地部分（新增 `camelSettle` 等，在动画更新之后调用），骆驼的行为、路线、动画片段都没改。

## 六、性能 `perf.json`

CI 同款测试（iPhone 13 视口，4 倍 CPU 降速，晴天），main 和本分支在同一会话里交替跑 4 轮，先后顺序轮换。每帧 JS 平均：本分支 19.3 / 21.4 / 14.8 / 14.8 毫秒，main 17.4 / 14.3 / 15.0 / 16.1 毫秒。均值 17.6 对 15.7，是 main 的 1.12 倍，在 1.15 倍以内，没有一帧超过 200 毫秒。
落地计算本身每帧两只骆驼合计不到 0.5 毫秒，差值主要是这台机器上的轮间波动。
