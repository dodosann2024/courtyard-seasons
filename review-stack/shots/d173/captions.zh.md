# d173 截图与视频说明

本轮按 #172 复审的三条意见继续做「草…随风而动的感觉；所有动物的脚印要对齐，不能凭空出现脚印」：
1. 草随风：风 1.0 时中远处的长叶叶尖一眼能看出顺风倒，阵风来时倒得更低；风 0.15 和原来一样几乎不动。
2. 鸵鸟脚印：鸵鸟（ostrich_v2ag）的模型、动画、行为一点没动，只改了脚印系统：在脚掌踩实的那一刻，按蒙皮后脚掌的实时中心落印。
3. 沙鼠跳跃落地留印：每次落到沙上，在真实的前后脚位置印一对脚印，空中不印。

所有数字都是在最终 bundle 上重新测的：修改前 main = `assets/desert.4c46dd446d.js`，修改后本分支 = `assets/desert.b609b040bf.js`，每个 json 里都写了 bundle。
#172 的吃草/喝水位置、新草、对齐的脚印，#171 骆驼贴地，都保留。没有加任何新元素。沙瀑、木架/营火石、毯子/水囊/陶罐/帐篷支架、打水漂、西奈飞蜥、风吹沙、沙丘变化、雨都没动。
所有截图和视频都隐藏了设置面板和界面（`panel_version.png` 除外，它就是拍面板的）。SwiftShader 软件渲染，画质比真机低。

## 一、草随风

- 原因：main 的草是按「高度平方」把顶点往下风方向平移（剪切），叶片没有转动，而是被拉长、斜切。风 1.0 时叶尖平均被拉长 32%，阵风时 52%，看起来像叶片被拉变形，不像被风压弯；丛里朝上风张开的叶片只是变直，整丛看不出往一个方向倒。
- 修改：只改了草的顶点着色器（vegMat）。每个顶点绕草丛根部、在风向所在的竖直平面里转动，越高转得越多；所有叶片都朝同一个下风倾角（72°）收拢：朝上风张开的叶片转得最多，本来就偏下风的转得最少，不会插进沙里。同时按弧线弦长（sin(a)/a）缩短到根部的距离，所以叶片是弯，不是拉长。倾倒量 = 风力^1.5 ×（0.3 + 1.5 × 阵风场），风小时更静，风大、阵风到时倒得更多；每丛有自己的相位，每片叶有自己的抖动。根部固定。草、芦苇、灌木各自的摆幅系数不变。
- `wind_grass_strip.jpg`：同一个固定机位（侧对风向，离草丛 3 米，高 0.75 米），从左到右：风 0.15、风 0.5、风 1.0、风 1.0 的阵风峰值。上排 main，下排本分支。风 0.15 两边都基本直立；风 1.0 本分支整片草丛都梳向右边（下风），长芦苇明显弯下；阵风峰值时草叶几乎贴向下风。
- `wind_0.15_to_1.0.mp4`：10 秒，同一机位。前 5 秒风 0.15，第 5 秒切换到 1.0（左下角显示当前风力），能看到草丛一起向右倒、阵风一阵阵过去。15 帧/秒渲染。
- `grass_wind.json`：两个 bundle 的叶尖位移，用各自着色器的弯曲公式，在场景里真实的草丛实例上计算（离镜头草丛 2–12 米的所有草/芦苇，每片叶上部 30% 的顶点，阵风时钟扫过约 54 秒）。普通风力只算阵风场 < 0.75 的草丛，阵风峰值只算 ≥ 0.75 的草丛。

| --- | --- | --- |
| 0.15 | 4.5 / 4.1° / 3.6% | 3.6 / 4.9° / 0.2% |
| 0.5 | 17.1 / 16.0° / 13.7% | 20.4 / 25.1° / 3.1% |
| 1.0 | 41.1 / 39.3° / 31.8% | 36.9 / 48.9° / 6.0% |
| 1.0 阵风峰值 | 66.8 / 60.2° / 51.9% | 44.0 / 62.1° / 6.8% |

main 在风 1.0 和阵风时的位移有一大部分来自叶片被拉长（31.8%、51.9%）；本分支叶片长度基本不变（6% 左右），位移全部来自真正的弯倒，所以倾角更大，看起来是被风压弯。

## 二、鸵鸟脚印（鸵鸟冻结，只改脚印系统）

- 原因：main 按步态动画里估算的落地相位和脚骨上的固定点落印，鸵鸟长脚掌从脚跟滚到脚趾，这个固定点和真正踩实的脚掌中心差好几厘米，偶尔还在脚没踩实时印出来。
- 修改：鸵鸟的模型、动画、行为都没改。脚印系统在每段步态里先算出每只脚的「支撑段」（脚底贴地的那一段相位）。到支撑段的中段，每帧在 CPU 上蒙皮这只脚的顶点，取离沙面最近的一圈的中心（按脚下沙面的坡度算高差），这一点贴住沙面、几乎不动的第一帧，就在这里按脚的朝向印一次。一次支撑只印一次。抬脚、滑动、动画切换混合中都不印。
- `trail_ostrich_before_after.jpg`：俯视，左边 main，右边本分支，一样的路线。
- `footprints.json` 里的鸵鸟：偏移 p95 从 5.6 厘米降到 1.5 厘米（最大 9.9 → 2.3），没有对应落地的脚印从 2 个降到 0 个。

## 三、沙鼠跳跃落地留印

- 原因：main 的沙鼠用「每秒最多几次」的令牌限制脚印，而且只在估算的落地相位印，大多数落地没有脚印（这次的路线上 925 次落地 0 个脚印，整群 1050 次落地 12 个）。
- 修改：沙鼠跳跃（hop_run）时，每只脚离开沙面 9 毫米以上算「起跳」，蒙皮后的脚底回到沙面 5 毫米以内的那一帧算「落地」，就在那只脚的实际位置印一个（前后脚分开，左右镜像），空中不印。沙鼠脚印不再受令牌限制。为了不让成群的沙鼠在黄昏把骆驼、鸵鸟的脚印提前顶掉，沙鼠脚印在脚印环形缓冲的最后五分之一里单独循环，只会替换更早的沙鼠脚印。
- `trail_gerbil_after.jpg`：本分支沙鼠跳过的一段，前后脚成对。main 在同一条路线上没有印出脚印，所以没有对比图。
- `footprints.json` 里的沙鼠：路线上本分支 907 次落地 907 个脚印（100%），没有对应落地 0 个，偏移 p95 0 厘米。`gerbilColony` 是整群沙鼠在黄昏自然活动 60 秒（不停放、不引导）：本分支 886 次落地 873 个脚印（97.6% 的落地有脚印），没有对应落地 0 个，偏移 p95 0 厘米（最大 9.2 厘米，仍在 10 厘米匹配范围内）；main 是 1050 次落地 12 个脚印（1.3%）。

## 五、吃草 / 喝水（最终 bundle 重测）

`graze.json`（d172 的方法，模拟 6 分钟）：吃草有效 = 低头最深时嘴离活草丛 ≤ 0.3 米；喝水有效 = 嘴在水面上方、与水面高差 ≤ 5 厘米。

| 动作 | main | 本分支 |
| --- | --- | --- |
| 单峰驼吃草 | 8 次，有效 100% | 6 次，有效 100% |
| 双峰驼吃草 | 本次没去吃 | 2 次，有效 100% |
| 双峰驼喝水 | 6 次，有效 100%（嘴入水 1.5–3.1 厘米） | 11 次，有效 100%（嘴入水 1.7–2.4 厘米） |
| 鸵鸟啄食（冻结，只报告） | 64 次，有效 6.3% | 62 次，有效 4.8% |

#172 的吃草/喝水位置保持不变。

## 六、版本与性能

- `panel_version.png`：面板底部显示「版本 b609b0」，对应 `desert.b609b040bf.js`。
- `perf.json`：同一会话里 main 和本分支交替跑 4 轮（顺序 pr, main, main, pr, pr, main, main, pr），晴天每帧 JS 平均：本分支 15.8 毫秒，main 15.0 毫秒（上限 main × 1.15 = 17.2 毫秒），8 次都没有超过 200 毫秒的帧。
- 另外，脚踢起的沙尘（spPuff）改用自己的随机数序列，这样脚印多印几个不会改变后面动物的随机选择（否则陆龟的行为会跟着变）。只影响沙尘粒子的随机散布。
