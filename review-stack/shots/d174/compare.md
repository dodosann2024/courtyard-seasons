# d174 沙漠 vs 空中海洋：细节差距对比与本轮选择

目标：沙漠场景的细节至少达到同一仓库里空中海洋（`/sea/`）的水平。本轮只能从沙漠**已有**元素里挑一到两个、和海洋里可比元素差距最大的来提升，不加新元素。

修改前 main = `assets/desert.b609b040bf.js`，修改后本分支 = `assets/desert.fb25e09688.js`。海洋没有改动（同一仓库 `src/sea.js`）。所有截图隐藏了设置面板和界面，SwiftShader 软件渲染，1280×720。

## 一、逐项对比（沙漠已有元素 ↔ 海洋可比元素）

| 沙漠已有元素 | 海洋里可比的元素 | 修改前的差距 |
| --- | --- | --- |
| **绿洲水面**（`pondU` 片元着色器） | 海面（Gerstner 波 + 法线细节 + 高光） | **最大**。海面有三种尺度的法线细节、按像素大小做 LOD，微表面（Beckmann）太阳高光加闪烁点，浪尖透光，水下沙盘上有焦散网。绿洲只有一层 3 个八度的值噪声法线（单一尺度、和风向无关），太阳高光是一个 `pow(·,220)` 光斑加一块块噪声斑点；看穿水面的沙底只是一种颜色乘一层噪声，没有焦散，没有沙纹；阳光、阴天、风小风大，水面质感几乎一样。 |
| **绿洲水边线**（同一个着色器的边缘） | 海缘的白浪泡沫花边（rim foam lace）、浪尖泡沫 | **第二大**。海缘有破碎的泡沫花边、细孔、随浪漂动。绿洲的水边只是按水深 0–5 厘米把透明度渐变掉，外加一圈「略暗的带」：边缘不动，没有弯月面亮线，没有泡沫，近看是一条模糊的渐变。 |
| 沙丘沙面 | 海底沙盘（沙纹 + 焦散） | 小。沙面已经有风纹、流沙、湿沙、脚印、雪、冰雹坑等多层细节，比海底沙盘丰富。 |
| 骆驼 / 鸵鸟 / 小动物 | 鲸、海龟、海鸟 | 小。#171–#173 已经做了贴地、脚印、步态；鸵鸟按要求冻结。 |
| 帐篷 / 营火 / 木架 | 帆船、帆、索具 | 小，且这些按要求不能动（帐篷支架、毯子、水囊、陶罐、木架/营火石都已封线）。 |
| 天空、雨、雪、风沙 | 天空、雨、雾 | 小。沙漠这几轮做过眼高雨、风沙、沙丘随风变化，和海洋同级。 |

结论：差距最大的两个都在**绿洲的水**上：① 水面本身，② 水边线。它们都是已有元素，改动只在绿洲水面的片元着色器和它的 uniform 里，不加任何网格、模型或新物体。

## 二、做了什么（只改 `pondU` 片元着色器）

**① 水面**
- 毛细波：在原来的三层涟漪上再叠两层更细的波纹，波峰垂直于风向、顺风漂移，按每像素覆盖的尺寸（`fwidth`）淡出，所以近处看得到细纹，远处不闪烁、不出摩尔纹（远处转成更宽的高光）。
- 风斑（cat's paws）：风扫过的地方一片片变粗糙、顺风移动，中间是镜面一样的平静带；远看是一块块略暗的水面，和真实小池塘一样。
- 太阳高光：保留原来的核心光斑，加一个按水面粗糙度变宽的微表面（Beckmann）高光瓣，配上近处细、远处粗两套闪烁点；逆光看太阳方向时，水面上是一片细碎的金色闪光，不再是几块白斑。
- 浪尖透光：低太阳在涟漪后面时，薄的波峰透出一点绿金色。
- 看穿水面的沙底：按视线和涟漪折射、晃动；沙底有顺风的沙纹和深一点的淤泥斑；浅水区有一张细的焦散光网在沙底上游动（两层不同尺寸）。焦散只在有太阳时出现，阴天、夜里、下雨、结冰时消失，风很小时变弱，水越深越淡。

**② 水边线**
- 水边会「舔岸」：水线沿岸一段段地往上爬、再退回去，风越大幅度越大，各段不同步。
- 弯月面：水刚碰到沙的地方有一条细亮线，映着天空（按像素宽度限制，不会锯齿）。
- 泡沫花边：舔岸带里有一圈破碎的细泡沫和气泡，随水的进退变化，风大时更多；夜里变暗，结冰时没有。原来的暗带保留但减弱，跟着舔岸的水线走。

## 四、修改前后能看出的差别

- 近距离（`water_close_before_after.jpg`）：修改前是一片均匀的蓝绿色，水边是一条模糊的暗色渐变；修改后浅水里能看到焦散光网在沙底游动、沙纹和淤泥斑，水边有弯月面亮线和一圈破碎的泡沫花边，水线在动。
- 朝太阳（`water_sun_before_after.jpg`）：修改前是几块噪声白斑；修改后是一片细碎的闪光，并且随风斑的粗糙程度变宽变窄，最接近海面的样子。
- 眼高（`water_eye_before_after.jpg`）：修改后水面能看出顺风的细纹和一块块风斑，近岸能看到沙底纹理；整体颜色和原来一致，没有改水的颜色和深浅。

## 五、没有动的

只改了绿洲水面的片元着色器和两个 uniform（风向直接复用沙面的 `uWD`，阴天程度 `WX.ovc`）。水的网格、深度、颜色、倒影、雨滴波纹、冰、雾都没改；小鱼、蟹、鸟、草、沙面都没改。没有加任何新元素，没有用 Tripo。
