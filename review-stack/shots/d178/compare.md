## 一、螃蟹跟着退水走，在水边待得更久（只用原有的 8 只螃蟹）

- 水退下去时，在岸上的螃蟹有 92% 的机会跟着走下去，并且**一路跟到这次退水的低点附近**（停在比低点高出这次退幅 30–55% 的地方）。main 只走一次，目标常常在水边以上，走到 2 厘米内就停。
- 跟着走的时候每 0.15 秒重新对准刚露出的水边，水一回头就停下。
- 走到以后在原地停 3–6 秒（原来 1–5 秒）。之后有 3–6 次机会在水边附近换个位置（沿岸左右偏 ±0.22 弧度，停在舔岸最高处以上 0.8–1.6 厘米），而不是马上回洞或走远。
- **让开保留**：水涌上来时照样往上让到最高处以上 1.4 厘米；跟水时让开的余量收紧到 3 毫米，所以只在水真的要漫过来时才让，不会在低点刚到时就跑。逃跑、回洞、对着镜头举钳这些原有行为优先，不受影响。

「刚露出的湿沙」= 螃蟹在当前水边以上、但在最近 3 秒内被水漫过的高度以下。「水边」= 舔岸最高处以上 3 厘米以内。

## 三、风 0.5 → 0.8 湿沙带和湿痕平滑过渡，强风时湿痕明显散得快

- 风对湿沙的作用改成从 0.5 开始的缓出曲线（1 − (1 − x)²，x = (风 − 0.5) × 2）。main 是 smoothstep(0.5, 1, 风)，0.5 到 0.65 几乎没变化，0.65 以后才突然变。
- 强风时湿痕的衰减更快（风 1 时 1.0 秒，原来 2.0 秒），而且按位置的噪声一块一块地散开，越老的湿痕散得越多，不是整片一起变淡。
- 风 ≤ 0.5、下雨、雨后湿沙和结冰时公式和 main 完全一样。

东岸，眼高 1.6 米。每个风速等到舔岸最高点刚好在画面中间时开始，录 45 帧（风 1 录 90 帧），每帧间隔 2 个模拟帧。
湿沙带亮度是按离水面的高度、在整段短片上平均的亮度；湿痕「剩下的湿度」= (干沙 − 亮度) / (干沙 − 水刚退时的亮度)，时间从水退到这个点以下 8 毫米开始算（和沙面着色器一样），数据在 `windstat.json`。

- 湿沙带的暗带宽度（比干沙暗 10% 以上的高度范围）：main 8.5 / 8.5 / 8 / 7.5 厘米，本分支 8.5 / 8 / 7.5 / 7.5 厘米（风 0.5 / 0.65 / 0.8 / 1）。
